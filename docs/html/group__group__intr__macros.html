◆ NUMBER_OF_TIMER_TICKS_LO

#define NUMBER_OF_TIMER_TICKS_LO   (9u)

Lower possible interrupt count.

  • PSOC 4 devices: 9u
  • PSOC 61 Programmable Line, PSOC 62 Performance Line, PSOC Control C3, XMC7000, and XMC5000 devices: 22u for configurations where the timer input clock and period produce about 22 to 27 terminal- count interrupts in 1000 us; 22u is the low end of that fixed pass window
