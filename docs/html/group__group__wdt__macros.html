◆ WDT_PERIOD

#define WDT_PERIOD   (900u)

To set the WDT period.


For PSOC 61 Programmable Line, PSOC 62 Performance Line, and PSOC 4 devices, WDT does a reset when this Limit is hit for the 3rd time.
For XMC7000 and XMC5000 devices, the Upper Limit is set to this value and will do a reset if WDT is not served before Upper Limit.
Note : This value differs for PSOC 61 Programmable Line, PSOC 62 Performance Line, PSOC Control C3, XMC7000, XMC5000, and PSOC 4 devices.

◆ IGNORE_BITS

#define IGNORE_BITS   (3U)

Sets the desired number of ignore bits.

To make WDT counter (32/16 - IGNORE_BITS) bits up counter.
