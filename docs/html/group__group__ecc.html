ECC (ECC STL module)

General Description

ECC hardware can correct single-bit (correctable) memory errors and report double-bit (non-correctable) memory errors through SysFault.

The STL ECC self-test APIs validate the non-correctable fault-reporting path by injecting ECC corruption and verifying the expected SysFault source.

Test sequence used by the APIs:

  • Configure SysFault mask/interrupt for ECC sources.
  • Inject ECC corruption into the target memory.
  • Read corrupted location to trigger ECC check.
  • Poll fault source and compare with expected non-correctable source.
