◆ stl_adc_config_mask_t

struct stl_adc_config_mask_t
Data Fields
bool skipAnaCal Exclude ANA_CAL entirely.
bool skipDigCal Exclude DIG_CAL entirely.
bool skipAnaCalAlt Exclude ANA_CAL_ALT entirely.
bool skipDigCalAlt Exclude DIG_CAL_ALT entirely.
uint32_t chSampleCtlMask[STL_ADC_CONFIG_MAX_CHAN] SAMPLE_CTL per-channel bitmask.

Must NOT mask PIN_ADDR/PORT_ADDR (channel routing); expected use is the ALT_CAL bit only.

uint32_t chTrCtlMask[STL_ADC_CONFIG_MAX_CHAN] TR_CTL per-channel bitmask.

Must NOT mask PRIO/PREEMPT_TYPE/ GROUP_END/DONE_LEVEL; expected use is the SEL field only.

uint32_t chPostCtlMask[STL_ADC_CONFIG_MAX_CHAN] POST_CTL per-channel bitmask.

Must NOT mask POST_PROC/LEFT_ALIGN/ SIGN_EXT/RANGE_MODE; expected use is AVG_CNT/SHIFT_R only.

uint32_t chIntrMaskMask[STL_ADC_CONFIG_MAX_CHAN] INTR_MASK per-channel bitmask: bits set here (per interrupt source) are excluded from comparison.
bool chSkipRangeCtl[STL_ADC_CONFIG_MAX_CHAN] RANGE_CTL per-channel skip: true excludes the whole register.
uint32_t channelSkipMask Coarse per-channel exclusion mask: bit N set to 1 excludes channel N's entire register set from Save/Verify, e.g.

for channels that are unused or fully re-configured by the application at runtime.
