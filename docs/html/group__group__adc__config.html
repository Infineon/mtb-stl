ADC Configuration Test (ADC Configuration Protection STL module)

General Description

This module provides APIs to capture and verify CRC-protected snapshots of SAR ADC and shared PASS-level configuration registers.

SelfTest_ADC_Config_Save and SelfTest_ADC_Config_Verify form a pair for capturing and verifying SAR ADC instance configuration snapshots, while SelfTest_ADC_MMIO_Config_Save and SelfTest_ADC_MMIO_Config_Verify form a pair for capturing and verifying shared PASS-level configuration snapshots.

Both SelfTest_ADC_Config_Save and SelfTest_ADC_MMIO_Config_Save capture only static configuration registers into caller-owned snapshots. Result, status, interrupt-request, and command registers (for example RESULT, STATUS, CH.INTR, CH.TR_CMD, CAL_UPD_CMD, TEST_CTL) are not captured. Run-time enable bits (CTL.ENABLED, DIAG_CTL.DIAG_EN, CH.ENABLE.CHAN_EN, PASS_CTL.DBG_FREEZE_EN) are masked internally, and application-provided masks exclude further dynamic fields.

The corresponding SelfTest_ADC_Config_Verify and SelfTest_ADC_MMIO_Config_Verify functions re-read the live registers, apply the stored masks, and compare them against their snapshots.
