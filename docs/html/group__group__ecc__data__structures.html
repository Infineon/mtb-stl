◆ stl_ecc_flash_cfg_t

struct stl_ecc_flash_cfg_t
Data Fields
bool eccEnable Required configuration: FLASH_CTL.ECC_EN target state.

Must be true.

bool rbusErrSilent Required configuration: FLASH_CTL.RBUS_ERR_SILENT target state.

Must be false.

bool checkFlashMacroEncoder When true, FM_CTL.ANA_CTL0.ECC_ENC_DIS is additionally verified to be 0.

The recommended value is true, which requires the caller to run in the Secure Main CM33 context: the Flash Macro register block is protection context restricted. An image that cannot read it must pass false, otherwise this read-only check itself raises a fault.

Data Fields
stl_ecc_flash_event_kind_t kind Event classification.
uint32_t wordAddress DATA0 word address; valid only when kind is not NONE.
