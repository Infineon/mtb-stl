uint8_t SelfTest_IPC_PPCA ( uint8_t testMask)

Tests selected PPCA IPC channel/interrupt-structure pairs in loopback mode.

Parameters
testMaskBitmask selecting which sub-test groups to execute. Use any combination of SELFTEST_IPC_PPCA_LOCK, SELFTEST_IPC_PPCA_DATA, SELFTEST_IPC_PPCA_NOTIFY, SELFTEST_IPC_PPCA_INTR, SELFTEST_IPC_PPCA_RELEASE_EVT, SELFTEST_IPC_PPCA_SILENT_REL, or SELFTEST_IPC_PPCA_ALL to run all groups.
Returns
OK_STATUS (0) - All selected groups passed
ERROR_STATUS (1) - No valid group selected, or a sub-test failed
