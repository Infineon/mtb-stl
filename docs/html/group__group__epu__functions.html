Performs a self-test of the EPU processing unit signal path by generating a software event on each PU in the specified range and verifying that the resulting trigger arrives as an interrupt via the COMBO and IRQ path.

The COMBO combiners (123 COMBO, 8 COMBO_FB) and EPU IRQ Generator are tested transitively through the PU signal path.

Note
The application must enable the PPCA_EPU IP block (e.g. via Cy_PPCA_EPU_Enable(PPCA_EPU)) before calling this function. The library does not toggle PPCA_EPU.CTRL to avoid affecting application-level power and clock policy.
Parameters
typePU sub-type to test: EPU_PU_TYPE_T1 (0) or EPU_PU_TYPE_T2 (1).
puInitialFirst PU index to test (inclusive).
PU_T1 range: 0..31, PU_T2 range: 0..15.
puEndLast PU index to test (inclusive).
PU_T1 range: 0..31, PU_T2 range: 0..15.
Returns
OK_STATUS (0) - Test passed
ERROR_STATUS (1) - HW self-test failed
ERROR_INCORRECT_USAGE_STATUS (4) - Invalid input parameters (no HW access performed)
